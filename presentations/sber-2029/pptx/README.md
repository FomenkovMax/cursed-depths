# PPTX-версия варианта A

`../variant-a-aurora.pptx` — тот же вариант A, ничего не изменено: тот же текст,
те же цифры, то же расположение. Отличие одно — теперь всё редактируется
в PowerPoint.

## Что можно править

| Что | Как |
|---|---|
| Любой текст | Клик по надписи — обычная правка. 58 отдельных надписей. |
| Цифры диаграмм | Правый клик по графику → **«Изменить данные»** → откроется лист Excel. Оба графика нативные. |
| Цвета, шрифты, размеры | Обычными средствами PowerPoint. |

Фон каждого слайда — картинка: градиент-«аврора», стеклянные карточки,
3D-объекты и свечения. Их в PowerPoint не воспроизвести формулами, поэтому они
запечены в фон. Текст и данные поверх — живые.

## Шрифты — установите перед показом

В презентации используются **Unbounded** (заголовки и цифры) и **Onest** (текст).
Их файлы лежат в `fonts-ttf/`. Установка: выделить все `.ttf` → правый клик →
**«Установить»**.

Если шрифты не установить, PowerPoint подставит замену: текст останется на
месте и будет читаемым, но заголовки станут уже, и вёрстка немного разъедется.
Оба шрифта бесплатные, с открытой лицензией (SIL OFL).

## Известные отличия от HTML-версии

1. **Анимации нет.** Живой градиент, плавающие 3D-объекты, счётчик цифр и рост
   столбцов — это возможности браузера. В PPTX слайды статичные.
2. **Цифры 35 / 47% / 100** в HTML залиты градиентом. В PowerPoint градиент по
   тексту так не задать, поэтому взят средний тон градиента — на глаз разница
   не видна, зато цифра осталась редактируемым текстом.
3. **Диаграммы рисует PowerPoint по-своему.** Толщина столбцов, отступы и
   положение подписей могут отличаться от HTML на несколько пикселей. Данные,
   цвета и порядок серий — те же.

Если нужен максимально точный вид — показывайте HTML-версию, она же лежит
рядом. PPTX нужен там, где данные будут править чужими руками.

## Как пересобрать

Если поправили HTML-версию и хотите обновить PPTX:

```bash
node extract.js ../variant-a-aurora.html ./build     # фоны + координаты из вёрстки
python3 build_pptx.py build ../variant-a-aurora.pptx # сборка
python3 preview.py ../variant-a-aurora.pptx ./preview # проверка раскладки
```

Требуется `pip install python-pptx pillow` и Playwright с Chromium.

Координаты каждой надписи снимаются прямо из DOM (`getBoundingClientRect`), а не
переписываются руками, — поэтому PPTX остаётся синхронным с HTML.

`preview.py` рисует слайды заново теми же шрифтами и показывает переносы строк
и вылеты текста. Это проверка **раскладки**, а не точный предпросмотр
PowerPoint: в этой среде нет LibreOffice Impress, поэтому файл в настоящем
PowerPoint не открывался. Перед защитой откройте его сами и пролистайте.
